Gérer plusieurs comptes Gmail dans une seule boîte de réception

Vos e-mails personnels, vos clients, un projet à côté. Une vue commune des boîtes de réception permet de repérer ce qui demande votre attention sans consulter chaque compte à tour de rôle. La bonne configuration dépend de l’appareil utilisé et de votre manière de traiter vos messages.

Sur téléphone, utilisez Toutes les boîtes de réception dans l’application Gmail. Sur ordinateur, Gmail permet de changer de compte, mais ne réunit pas leurs boîtes de réception. Définissez d’abord ce que signifie « une seule boîte de réception »

Deux objectifs sont possibles. Vous souhaitez peut-être une vue commune : les messages restent dans leurs comptes respectifs, mais vous les lisez et les gérez dans une seule interface. Ou vous souhaitez recevoir les messages dans un compte principal : les nouveaux e-mails des autres adresses y arrivent sous forme de copies transférées.

Imaginez trois comptes Gmail : personnel, indépendant et projet. Les voir ensemble aide à établir les priorités de la journée. Distinguer leurs identités reste tout aussi essentiel : archiver un message de projet doit agir sur la bonne boîte, et une réponse à un client doit partir de votre adresse professionnelle.

  • Vous utilisez surtout votre téléphone ? Commencez par la vue commune intégrée à Gmail sur mobile.
  • Vous consultez rarement votre deuxième compte ? Le changement de compte peut suffire.
  • Vous voulez recevoir les nouveaux e-mails à une adresse Gmail principale ? Envisagez le transfert.
  • Vous devez gérer ensemble les comptes d’origine sur ordinateur ? Envisagez une extension ou un logiciel de messagerie multicomptes.

Une vue unifiée ne fusionne ni les identités Google, ni les fichiers Drive, ni les réglages ou les quotas de stockage. Chaque compte reste le vôtre et conserve sa connexion distincte.

Solution 1 : passer d’un compte Gmail à l’autre sur ordinateur

Google permet de se connecter à plusieurs comptes dans une même session du navigateur. Ouvrez Gmail, sélectionnez votre photo de profil ou votre initiale, ajoutez un autre compte et connectez-vous. Ce menu permet ensuite de choisir la boîte à consulter, sans vous déconnecter à chaque fois.

C’est une solution adaptée si vous préférez des boîtes distinctes. Vous pouvez les garder dans des onglets séparés ou utiliser les profils Chrome pour séparer plus largement votre activité de navigation. En contrepartie, chaque boîte doit toujours être consultée séparément.

« Plusieurs boîtes de réception » est une autre fonctionnalité

Sur ordinateur, le type de boîte Gmail Plusieurs boîtes de réception crée des sections à partir de recherches ou de libellés dans la boîte actuellement ouverte. Il aide à organiser cette boîte, mais ne connecte pas à lui seul des comptes Google distincts. De même, se connecter à plusieurs comptes ne crée pas sur le Web la vue Toutes les boîtes de réception de l’application mobile.

Documentation Google : se connecter à plusieurs comptes et types de boîtes de réception Gmail.

Solution 2 : utiliser Toutes les boîtes de réception dans l’application Gmail

Gmail pour Android, iPhone et iPad propose une vue commune intégrée. Ajoutez vos comptes Gmail depuis le menu de votre profil avec Ajouter un autre compte, puis choisissez Google et connectez-vous. Ouvrez ensuite le menu en haut à gauche et sélectionnez Toutes les boîtes de réception.

C’est souvent le point de départ le plus simple si vous traitez vos e-mails sur téléphone. Les messages reçus s’affichent ensemble sans transfert vers une adresse principale. Ajouter des comptes dans l’application ne crée pas de boîte commune sur mail.google.com sur votre ordinateur.

Instructions officielles : Gmail pour Android et Gmail pour iPhone et iPad.

Solution 3 : transférer les nouveaux messages vers un compte Gmail principal

Le transfert convient si vous souhaitez une seule destination pour les nouveaux messages et acceptez de gérer des copies. Dans chaque compte Gmail source, ouvrez Paramètres → Voir tous les paramètres → Transfert et POP/IMAP (ou Transfert). Ajoutez l’adresse de destination et validez la demande depuis celle-ci. Revenez ensuite aux paramètres du compte source pour activer le transfert et enregistrer. Choisissez ce qu’il advient de la copie d’origine.

Le transfert automatique concerne les nouveaux messages, sauf les spams ; il ne déplace pas votre historique. Des filtres permettent de ne transférer que certains messages. Lire ou archiver une copie transférée ne synchronise pas cette action avec la boîte d’origine.

Vérifiez l’adresse utilisée pour répondre

Le transfert ne configure pas l’identité d’envoi. Pour répondre avec une autre adresse Gmail qui vous appartient, configurez et validez séparément l’option Gmail Envoyer des e-mails en tant que, puis vérifiez l’adresse de l’expéditeur avant l’envoi.

Consultez les instructions Google sur le transfert et l’option Envoyer des e-mails en tant que. Pour un compte professionnel ou scolaire, vérifiez les règles de transfert de votre organisation.

Vous suivez un ancien tutoriel ?

Google abandonne Gmailify et la fonction « Consulter d’autres comptes de messagerie » utilisant POP pour les comptes tiers. D’après le calendrier publié, les nouveaux utilisateurs ne sont plus pris en charge après le premier trimestre 2026 ; les utilisateurs existants peuvent continuer jusqu’en janvier 2027. Ces changements sont distincts du transfert entre comptes Gmail et de la vue Toutes les boîtes de réception sur mobile. Consultez les consignes actuelles de transition de Google avant de vous appuyer sur une ancienne configuration POP.

Solution 4 : utiliser une extension pour une vue Gmail unifiée

Une extension multicomptes peut fournir un espace commun tout en conservant le lien entre les messages et leurs comptes d’origine. Avant de l’installer, vérifiez les services de messagerie pris en charge, les actions disponibles, le fonctionnement de l’autorisation et les fonctions payantes. Un simple compteur de messages non lus diffère d’une boîte complète dans laquelle travailler.

La place de Difmeil

Difmeil est une extension Chrome avec une fenêtre rapide accessible depuis la barre d’outils et une boîte de réception en pleine page. Elle rassemble les comptes Gmail connectés, permet de se concentrer sur un seul compte et propose des notifications pour plusieurs comptes.

Vous pouvez lire les messages, les marquer comme lus ou non lus, les archiver ou les mettre à la corbeille, mais aussi rédiger, répondre et transférer. Ces actions portent sur la boîte Gmail connectée, et non sur une copie transférée. Utilisez la recherche en pleine page pour rechercher dans plusieurs comptes ; celle de la fenêtre rapide se limite aux e-mails déjà chargés.

Le forfait gratuit comprend jusqu’à trois comptes, la boîte unifiée, la lecture en pleine page, la recherche et les notifications de base. Pro ajoute davantage de comptes et des réglages avancés de personnalisation et de notifications. Consultez le comparatif actuel des forfaits pour les détails.

Difmeil convient si vous travaillez au quotidien dans Chrome avec des comptes Gmail. Ce n’est ni une application mobile ni un client pour Outlook, Yahoo ou des comptes IMAP génériques. Pour plusieurs fournisseurs, cherchez un client qui les prend explicitement en charge. Nous développons Difmeil ; les autres solutions présentées peuvent mieux convenir à votre organisation.

Configurer Difmeil avec plusieurs comptes Gmail

Suivez ces étapes dans Chrome sur ordinateur. Les noms des commandes ci-dessous correspondent à l’interface française de Difmeil ; les écrans de connexion Google peuvent varier selon votre compte et vos paramètres de sécurité.

  1. Installer depuis la fiche officielle

    Ouvrez Difmeil sur le Chrome Web Store, sélectionnez Ajouter à Chrome et lisez la demande d’installation de Chrome. Confirmez si vous souhaitez continuer. Ouvrez Difmeil depuis le menu Extensions de Chrome ; vous pouvez épingler son icône pour y accéder plus facilement.

  2. Ajouter votre premier compte Gmail

    Cliquez sur l’icône Difmeil. Dans l’écran initial Connectez votre premier compte, sélectionnez Ajouter un compte. La procédure Google OAuth démarre : choisissez le compte Google à connecter et effectuez la connexion ou la validation en deux étapes demandée par Google.

  3. Examiner la demande d’accès de Google

    Lisez l’écran de consentement avant d’accepter. L’implémentation actuelle demande des informations d’identité de base, l’autorisation de lire et gérer les messages Gmail, d’envoyer des e-mails et un accès en lecture seule aux « Autres contacts » Google pour les photos des expéditeurs et les suggestions de destinataires. Ces accès servent à la boîte, aux actions sur les messages et à la rédaction. Difmeil ne vous demande pas de saisir votre mot de passe Google dans l’extension : la connexion se fait auprès de Google.

    Lisez la politique de confidentialité pour comprendre d’abord le traitement des données. Les requêtes de messagerie circulent entre votre navigateur et Google. Un service d’autorisation échange et renouvelle les jetons sans les stocker. Si un compte géré bloque l’accès, renseignez-vous auprès de votre administrateur.

  4. Connecter les autres comptes

    Après la connexion du premier compte, ouvrez les commandes de comptes dans la fenêtre rapide et choisissez de nouveau Ajouter un compte. Autorisez séparément chaque compte Google supplémentaire. Vérifiez le compte choisi à chaque fois : être connecté à Gmail dans Chrome n’accorde pas automatiquement l’accès à Difmeil. La barre latérale en pleine page comporte aussi la commande Ajouter un compte.

  5. Ouvrir la boîte commune

    Choisissez Ouvrir la vue complète dans la fenêtre rapide, puis Tous les comptes dans la barre latérale en pleine page pour travailler sur les comptes connectés. Sélectionnez un compte précis pour vous concentrer dessus. Commencez par quelques messages récents et vérifiez l’identité du compte avant toute action.

  6. Lire, agir et régler les notifications

    Ouvrez un message pour le lire. Utilisez les actions lu/non lu, archiver ou corbeille selon vos besoins ; vérifiez le compte expéditeur lorsque vous rédigez ou répondez. Ouvrez Réglages pour consulter Notifications et les interrupteurs de notification par compte dans Mes comptes. Les notifications de base sont disponibles avec le forfait gratuit ; les règles avancées et les plages Ne pas déranger nécessitent Pro.

Vous pouvez toujours ouvrir Gmail directement si nécessaire. Installer Difmeil n’exige ni transfert automatique ni remplacement de vos adresses Gmail actuelles.

Une routine simple pour travailler sur plusieurs comptes

Une boîte commune est surtout utile lorsqu’elle permet de déterminer clairement la prochaine action. Essayez cette routine avant d’ajouter des règles ou de modifier toute votre organisation.

  • Parcourez l’ensemble, concentrez-vous sur un compte. Utilisez Tous les comptes pour repérer les urgences, puis sélectionnez votre compte professionnel pour une séance ciblée.
  • Vérifiez l’identité avant d’envoyer. Une conversation personnelle peut côtoyer une demande de client. Vérifiez le compte et le destinataire avant de répondre.
  • Archivez une fois la décision prise. Réservez la boîte de réception aux messages qui demandent encore une action, sans faire du statut non lu votre seule liste de tâches.
  • Choisissez vos alertes. Activez les notifications pour les comptes où les interruptions sont utiles. Si Gmail ou une autre application vous avertit aussi, vérifiez les deux pour éviter les doublons.
  • Testez la configuration. Envoyez-vous un message de test sans information sensible, vérifiez le compte destinataire et assurez-vous que l’action choisie apparaît sur ce compte dans Gmail.

Si un compte ou un message manque

La vue commune n’affiche qu’un compte

Vérifiez que chaque compte a été connecté via Google, et pas seulement ouvert dans un onglet Gmail. Dans Difmeil, sélectionnez Tous les comptes et vérifiez qu’aucun compte n’est masqué dans la boîte. Effacez les filtres de compte ou de messages non lus susceptibles de réduire la liste.

Un compte demande une reconnexion

Suivez la procédure proposée avec le bon compte Google. Si l’autorisation échoue, lisez l’erreur Google : une règle de l’organisation ou une autorisation retirée peut demander une autre démarche. Ne changez pas vos mots de passe à répétition simplement parce qu’une boîte doit être autorisée de nouveau.

Vous ne trouvez pas un ancien message

La fenêtre rapide recherche dans les messages chargés. Essayez la recherche Gmail en pleine page pour élargir la recherche, ou ouvrez le compte d’origine dans Gmail pour vérifier que le message y figure. Le transfert, lui, ne rapatrie pas automatiquement tout l’historique dans le compte de destination.

Vous ne recevez pas de notifications

Vérifiez les réglages globaux et par compte de Difmeil, puis ceux de Chrome et de votre système d’exploitation. Les modes silencieux peuvent bloquer les alertes. Les notifications signalent les nouveaux messages, mais ne doivent pas être votre seul moyen de surveiller une boîte importante. Pour un problème avec le produit, contactez l’assistance Difmeil.

Questions fréquentes

Puis-je réunir deux comptes Gmail sans les fusionner ?

Oui. Toutes les boîtes de réception sur Gmail mobile et une interface multicomptes comme Difmeil permettent de les consulter ensemble en conservant leurs identités distinctes. Cela ne fusionne ni les comptes Google ni leur stockage.

Où trouver Toutes les boîtes de réception sur Gmail pour ordinateur ?

L’interface Web de Gmail propose le changement de compte et plusieurs types de boîtes, dont Plusieurs boîtes de réception. Elle n’offre pas la même vue multicomptes Toutes les boîtes de réception décrite dans les instructions mobiles de Google. Utilisez l’application Gmail sur téléphone, le transfert de copies entrantes ou une interface multicomptes sur ordinateur.

Dois-je transférer mes e-mails pour utiliser Difmeil ?

Non. Vous autorisez chaque compte Gmail avec Google OAuth. Difmeil travaille avec ces comptes connectés ; aucune règle de transfert n’est nécessaire à son installation.

Puis-je répondre avec la bonne adresse Gmail ?

Difmeil permet de répondre et de rédiger depuis les comptes connectés. Vérifiez le compte expéditeur avant l’envoi. Si vous rassemblez plutôt des messages transférés dans une boîte Gmail, configurez séparément Envoyer des e-mails en tant que pour une autre adresse qui vous appartient.

Difmeil est-il gratuit pour plusieurs comptes ?

Le forfait gratuit comprend jusqu’à trois comptes Gmail, une boîte unifiée, la lecture en pleine page, la recherche et les notifications de base. Davantage de comptes et les fonctions avancées de notification et de personnalisation nécessitent Pro. Consultez le comparatif des forfaits.

Difmeil prend-il en charge Outlook ou mon téléphone ?

Difmeil est une extension Chrome pour les comptes Gmail. Ce n’est pas une application mobile et elle ne connecte pas les boîtes Outlook, Yahoo ou IMAP génériques. L’application mobile Gmail ou un logiciel prenant explicitement en charge ces fournisseurs peut répondre à ces besoins.

Puis-je utiliser un compte Gmail professionnel ou scolaire ?

Un compte Gmail Google Workspace peut être soumis aux règles d’accès des applications tierces de votre organisation. Consultez votre administrateur si Google bloque l’autorisation. Posséder l’adresse ne vous permet pas forcément de contourner ces règles.

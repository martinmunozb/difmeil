Notifications Gmail · Guide pratique

Recevoir les notifications de plusieurs comptes Gmail

Vous pouvez être connecté à plusieurs comptes Gmail et manquer tout de même un message important. Pour y remédier, vérifiez comment chaque compte envoie ses alertes, ce que votre appareil autorise et quelles notifications méritent vraiment votre attention.

La réponse rapide

Vous n’avez pas besoin de changer constamment de compte pour recevoir des alertes. Sur ordinateur, configurez les notifications de bureau Gmail pour chaque boîte et autorisez les notifications dans le navigateur et le système d’exploitation. Sur mobile, vérifiez les réglages de chaque compte dans l’application Gmail. Dans Chrome, Difmeil offre une autre approche : connectez vos comptes une fois et gérez leurs notifications avec une boîte de réception unifiée.

Commencez par les notifications de bureau de Gmail

Changer de compte et recevoir des notifications sont deux choses distinctes. Vous pouvez rester connecté à plusieurs comptes Google ; consulter une boîte ne déconnecte pas les autres. L’essentiel est que chaque boîte ait ses alertes configurées et que le navigateur puisse les afficher.

  1. Ouvrez le compte Gmail à configurer.
  2. Accédez à Paramètres → Voir tous les paramètres, puis cherchez Notifications de bureau.
  3. Choisissez les notifications de nouveaux messages ou de messages importants, puis enregistrez.
  4. Autorisez les notifications du site si le navigateur vous le demande. Répétez le réglage Gmail pour les autres comptes.

Google décrit ces alertes lorsque Gmail est ouvert et connecté dans un navigateur compatible. Ne supposez pas qu’elles arriveront lorsque Gmail est fermé. Si les catégories de boîte de réception sont activées, les alertes de nouveaux messages concernent la catégorie Principale ; celles des messages importants reposent sur le classement de Gmail. Consultez les instructions Google sur les notifications de bureau.

Pour un deuxième compte consulté occasionnellement, cela peut suffire. Avant toute installation, testez votre configuration avec un nouveau message envoyé à chaque compte pour voir si elle répond à vos besoins.

Vérifiez aussi le navigateur et le système d’exploitation

Le réglage des notifications Gmail n’est qu’un niveau. L’autorisation du site dans Chrome et les réglages du système d’exploitation en sont d’autres. Un réglage de messagerie ne peut pas contourner une autorisation bloquée ou le mode silencieux de l’appareil.

Pour les alertes du site Gmail dans Chrome, ouvrez Paramètres → Confidentialité et sécurité → Paramètres des sites → Notifications et vérifiez l’autorisation de Gmail. Vous pouvez aussi la consulter depuis le bouton d’informations du site à côté de la barre d’adresse. Vérifiez que votre système autorise les notifications Chrome, puis examinez les réglages Concentration ou Ne pas déranger.

Chrome peut retirer les autorisations des sites inutilisés : vérifiez-les de nouveau si les alertes fonctionnaient auparavant. Cette autorisation du site diffère de la capacité d’une extension à afficher des notifications : autoriser Gmail ne règle pas les interrupteurs par compte de Difmeil. Consultez les consignes de notification de Chrome pour les commandes actuelles.

Pour tester, gardez Gmail ouvert, désactivez temporairement le mode silencieux et envoyez un message sans information sensible à chaque boîte. Si un seul compte reste silencieux, examinez d’abord ses réglages ; si tous le sont, vérifiez les réglages communs du navigateur ou de l’appareil.

Sur mobile, configurez chaque compte Gmail

L’application Gmail peut vous avertir pour plusieurs comptes. Vérifiez les réglages de chaque compte ajouté ; celui qui est affiché à l’écran n’est pas le seul à pouvoir recevoir des alertes.

Android

Dans Gmail, ouvrez le menu, accédez aux Paramètres, choisissez un compte et vérifiez les Notifications par e-mail. Pour des alertes par libellé, vérifiez la synchronisation et les notifications du libellé concerné. Si rien n’arrive, contrôlez la synchronisation Gmail et les autorisations de notification de l’application dans Android. Les instructions Google pour Android expliquent les niveaux disponibles.

iPhone et iPad

Autorisez les notifications Gmail dans les réglages de l’appareil, puis vérifiez les Notifications par e-mail dans les paramètres Gmail de chaque compte et choisissez le niveau adapté. Consultez les instructions Google pour iPhone et iPad.

Toutes les boîtes de réception est une vue de lecture, pas un interrupteur général de notifications. Rassembler les messages dans cette vue ne remplace pas les préférences d’alerte par compte. Les notifications mobiles et celles de l’ordinateur doivent également être configurées séparément ; modifier les unes ne configure pas les autres.

Quelle configuration de notifications convient à votre quotidien ?

Décidez où vous souhaitez être interrompu avant de choisir un outil. Une alerte sur téléphone peut suffire pour des messages occasionnels ; un espace sur ordinateur peut être plus utile si vous devez agir immédiatement.

Sur petit écran, faites défiler le tableau horizontalement. Au clavier, placez le focus sur le tableau et utilisez les flèches.

Configurer les notifications de vos comptes dans Difmeil

Difmeil est une extension Chrome pour les comptes Gmail. Elle vérifie les boîtes connectées en arrière-plan et peut afficher des notifications natives du système sans onglet Gmail ouvert. Ces vérifications sont périodiques : les alertes ne sont donc pas garanties instantanées. Chrome doit fonctionner, l’extension être activée et le compte autorisé.

  1. Installer l’extension officielle

    Ouvrez Difmeil sur le Chrome Web Store, choisissez Ajouter à Chrome et examinez la demande d’installation. Ouvrez Difmeil depuis le menu Extensions de Chrome ; épinglez son icône pour un accès rapide.

  2. Connecter chaque compte avec Google

    Sélectionnez Ajouter un compte dans la fenêtre rapide et suivez Google OAuth pour le compte Gmail souhaité. Répétez depuis les commandes de comptes pour les autres comptes. La connexion se fait auprès de Google ; ne saisissez pas votre mot de passe dans l’extension. Pour la procédure complète, consultez la connexion de plusieurs comptes Gmail.

    Lisez la demande de consentement : l’implémentation demande des informations d’identité de base, les autorisations de lecture, de gestion et d’envoi Gmail ainsi que l’accès en lecture seule aux Autres contacts pour les photos d’expéditeurs et les suggestions de destinataires. Difmeil est aussi un client de messagerie ; son accès est donc plus large que celui d’un simple compteur. Lisez la politique de confidentialité avant d’autoriser l’accès. Les requêtes de messagerie circulent entre le navigateur et Google ; un service d’autorisation échange et renouvelle les jetons sans les stocker.

  3. Activer les alertes souhaitées

    Ouvrez Réglages → Notifications et vérifiez l’interrupteur principal. Dans Mes comptes, vérifiez celui de chaque compte connecté. Un compte masqué dans la boîte de réception est aussi exclu des notifications : laissez visibles les comptes à surveiller.

  4. Vérifier l’appareil et tester

    Autorisez les notifications Chrome dans votre système et vérifiez les modes silencieux. Laissez Chrome fonctionner et envoyez un nouveau message de test à chaque compte. Utilisez un nouveau message de test : les messages non lus existants peuvent déjà avoir été signalés ou être exclus par les réglages ; leur nombre ne garantit pas une alerte.

  5. Choisir comment traiter les messages

    La fenêtre de la barre d’outils offre une vue rapide ; Ouvrir la vue complète ouvre la boîte en pleine page. Sélectionnez Tous les comptes pour réunir les messages ou un seul compte pour vous concentrer dessus. Lisez, répondez, marquez les messages comme lus, archivez-les ou mettez-les à la corbeille selon vos besoins.

Évitez d’utiliser involontairement deux systèmes d’alerte bruyants. Après les tests, décidez si vous souhaitez les alertes du site Gmail, celles de Difmeil ou les deux. En désactiver un relève de votre organisation ; ce n’est pas nécessaire au fonctionnement de l’autre.

Qu’est-ce qui est gratuit et qu’est-ce qui nécessite Pro ?

Le forfait gratuit comprend jusqu’à trois comptes Gmail, la boîte unifiée, la lecture en pleine page, la recherche et les notifications de base. Vous pouvez activer ou désactiver les notifications globalement et par compte.

Pro permet davantage de comptes et ajoute des réglages avancés : plages Ne pas déranger, règles d’expéditeur et d’objet, filtres de catégories et réglages spécifiques supplémentaires par compte. Si votre priorité est simplement de repérer les messages de deux ou trois comptes, commencez par les réglages de base. Si vous souhaitez être interrompu par les clients, mais pas par les mises à jour courantes, examinez les règles avancées.

Les préférences Pro restent enregistrées lorsque l’accès expire, mais les règles premium cessent de s’appliquer ; les réglages gratuits restent disponibles. Revérifiez votre configuration après un changement de forfait au lieu de supposer qu’un ancien filtre premium fonctionne toujours. Le comparatif actuel des forfaits fait référence pour les fonctions incluses.

Commencez avec peu d’alertes utiles. Par exemple, gardez les notifications d’un compte professionnel pendant une séance de travail et rendez silencieux un compte de projet peu prioritaire. Davantage de notifications ne signifie pas toujours une meilleure configuration.

Examinez un niveau à la fois

Un seul compte reste silencieux

Confirmez qu’il est connecté et autorisé. Vérifiez son interrupteur de notification, s’il est masqué et les règles applicables. Si Gmail lui-même reste silencieux, vérifiez le niveau de notification du compte et ses catégories. Utilisez un nouveau message de test sans attendre qu’un ancien message non lu déclenche une nouvelle alerte.

Tous les comptes restent silencieux

Vérifiez l’interrupteur global, les autorisations du système et le mode silencieux. Dans Difmeil, assurez-vous que Chrome fonctionne, que l’extension est activée et que vous êtes connecté à Internet. Les vérifications périodiques peuvent être retardées par le navigateur ou l’appareil ; ne considérez pas les alertes e-mail comme un canal garanti en temps réel.

Vous recevez des alertes en double

Identifiez les applications qui les envoient. Gmail, Difmeil et un téléphone peuvent chacun signaler le même message. Désactivez la source superflue si vous n’en avez pas besoin plutôt que de déconnecter un compte qui fonctionne.

Une règle semble ignorer un message important

Comparez la règle à l’expéditeur, l’objet et la catégorie du message. Dans Difmeil, les expéditeurs bloqués priment sur les règles d’inclusion et un message lu ne déclenche pas de notification. Pour diagnostiquer le problème, simplifiez d’abord les règles, puis réintroduisez-les une par une. Si nécessaire, contactez l’assistance Difmeil sans envoyer le contenu de messages privés.

Questions fréquentes

Gmail peut-il m’avertir pour deux comptes en même temps ?

Oui. Configurez les préférences de notification de chaque compte. Sur mobile, vérifiez chaque compte ajouté dans Gmail et autorisez les notifications de l’application. Sur ordinateur, vérifiez les réglages de la boîte Gmail, l’autorisation du navigateur et ceux de l’appareil.

Dois-je afficher un compte pour recevoir ses notifications ?

Non. Changer la boîte affichée diffère de la configuration de ses alertes. Gardez les comptes concernés connectés et vérifiez les conditions de l’application utilisée.

Difmeil a-t-il besoin d’onglets Gmail ouverts ?

Non. Ses vérifications en arrière-plan ne nécessitent pas d’onglet Gmail ouvert. Chrome doit fonctionner, Difmeil être activé et le compte connecté. Les alertes dépendent des vérifications périodiques et des réglages de notification de l’appareil.

Difmeil m’avertit-il si Chrome est complètement fermé ?

Ne comptez pas dessus. Difmeil fonctionne comme une extension Chrome, et non comme un service de notification distinct. Laissez Chrome fonctionner lorsque vous voulez qu’il vérifie vos messages.

Puis-je rendre un seul compte Gmail silencieux ?

Oui. L’interrupteur de notification de base par compte de Difmeil est disponible avec le forfait gratuit. Les réglages spécifiques avancés et les plages horaires nécessitent Pro. Gmail mobile propose aussi des préférences de notification par compte.

Pourquoi vois-je des messages non lus sans recevoir d’alerte ?

Un compteur de non lus ne garantit pas une nouvelle notification. Un message peut avoir déjà été signalé, être lu avant une vérification ou être exclu par les réglages. Utilisez un nouveau message pour tester la configuration.

Toutes les boîtes de réception active-t-il les notifications de chaque compte mobile ?

Non. Cette fonction rassemble la vue de lecture. Vérifiez séparément les réglages de notification de chaque compte et l’autorisation de l’application Gmail sur l’appareil.

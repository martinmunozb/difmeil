Política de Privacidade do Difmeil

Última atualização: 7 de setembro de 2026 · Español · English · Français · Deutsch

O Difmeil é uma extensão de navegador criada para ajudar o usuário a gerenciar e visualizar seus e-mails de forma mais confortável a partir do próprio navegador.

Esta política de privacidade explica quais dados o Difmeil pode tratar, para que são usados e quais direitos o usuário tem.

Dados que o Difmeil pode tratar

O Difmeil pode acessar determinados dados da conta Google/Gmail do usuário, desde que o usuário conceda as permissões necessárias por meio do OAuth do Google.

Dependendo das funcionalidades usadas, a extensão pode tratar:

  • Endereço de e-mail do usuário.
  • Lista de e-mails.
  • Remetente, destinatário, assunto, data e marcadores dos e-mails.
  • Status de leitura, favoritos, arquivamento ou outras ações de organização.
  • Conteúdo dos e-mails, apenas quando necessário para exibi-lo ao usuário dentro da extensão.
  • Dados técnicos básicos necessários para o funcionamento da extensão.

O Difmeil não vende dados pessoais do usuário nem os utiliza para publicidade de terceiros.

Finalidade do tratamento

Os dados são usados exclusivamente para:

  • Permitir que o usuário visualize, organize e gerencie seus e-mails.
  • Executar ações solicitadas pelo usuário, como marcar e-mails como lidos, arquivá-los, excluí-los ou enviá-los.
  • Melhorar a experiência de uso dentro da extensão.
  • Manter a segurança e o correto funcionamento do serviço.

Uso de dados do Google

O uso e a transferência de informações recebidas das APIs do Google são feitos de acordo com a política de dados do usuário dos serviços de API do Google, incluindo seus requisitos de Uso Limitado (Limited Use).

O Difmeil solicita apenas as permissões necessárias para fornecer suas funcionalidades. Os dados obtidos por meio das APIs do Google não são usados para publicidade, venda de dados, elaboração de perfis comerciais nem cessão a terceiros não necessários para a prestação do serviço.

Permissões do Google solicitadas

Para que o Difmeil funcione corretamente, a extensão pode solicitar permissões de acesso à conta Google do usuário por meio do OAuth. Essas permissões são usadas somente para executar as funções que o usuário solicita dentro da extensão.

O Difmeil pode solicitar as seguintes permissões:

  • https://www.googleapis.com/auth/gmail.modify: permite ler, organizar e modificar e-mails do Gmail, por exemplo marcá-los como lidos, arquivá-los, aplicar marcadores ou movê-los quando o usuário realiza uma ação dentro da extensão.
  • https://www.googleapis.com/auth/gmail.send: permite enviar e-mails a partir da conta do Gmail do usuário somente quando o usuário solicita expressamente o envio pelo Difmeil.
  • https://www.googleapis.com/auth/contacts.other.readonly: permite consultar contatos e outros contatos do Google em modo somente leitura, para facilitar funções como o preenchimento automático de destinatários ou a identificação de contatos.

O Difmeil não usa essas permissões para vender dados, exibir publicidade personalizada, criar perfis comerciais ou compartilhar informações com terceiros não necessários para a prestação do serviço.

Os tokens de autenticação são gerenciados de forma segura e usados somente para manter a sessão e executar as funções autorizadas pelo usuário. A configuração local da extensão pode ser salva em chrome.storage.local para lembrar as preferências do usuário no navegador.

Armazenamento de dados

O Difmeil pode armazenar certos dados localmente no navegador do usuário para lembrar preferências, configurações ou melhorar o funcionamento da extensão.

Salvo quando estritamente necessário para prestar o serviço, o Difmeil não armazena o conteúdo dos e-mails em servidores próprios.

Quando necessário para o funcionamento técnico da extensão, o Difmeil pode usar uma função de backend segura para concluir o processo OAuth e trocar códigos de autorização por tokens de acesso. Esses tokens são usados somente para autenticar o usuário e executar as ações autorizadas.

Compartilhamento de dados com terceiros

O Difmeil não vende nem aluga dados pessoais.

Os dados só poderão ser compartilhados quando necessário para:

  • Cumprir obrigações legais.
  • Prestar o serviço solicitado pelo usuário.
  • Manter a segurança técnica da extensão.
  • Usar provedores técnicos necessários para o funcionamento do serviço, sempre sob medidas adequadas de proteção.

Segurança

O Difmeil aplica medidas razoáveis para proteger os dados do usuário contra acessos não autorizados, perda, alteração ou uso indevido.

Ainda assim, nenhum sistema de informática é totalmente seguro, por isso não é possível garantir segurança absoluta.

Retenção de dados

Os dados serão conservados apenas pelo tempo necessário para cumprir as finalidades descritas nesta política, ou enquanto o usuário mantiver a extensão instalada e conectada.

O usuário pode revogar o acesso do Difmeil à sua conta Google a qualquer momento pelas configurações de segurança da sua conta Google.

Direitos do usuário

O usuário pode exercer seus direitos de acesso, retificação, eliminação, oposição, limitação do tratamento e portabilidade escrevendo para: support@difmeil.com

Também pode apresentar uma reclamação junto à Agência Espanhola de Proteção de Dados (Agencia Española de Protección de Datos) caso considere que o tratamento dos seus dados não está em conformidade com a regulamentação aplicável.

Menores de idade

O Difmeil não é dirigido especificamente a menores de idade. Se um menor usar a extensão, deverá fazê-lo com autorização de seus pais, tutores ou representantes legais quando exigível.

Alterações nesta política

O Difmeil poderá atualizar esta política de privacidade quando necessário devido a mudanças legais, técnicas ou funcionais. A versão atualizada estará disponível na página oficial de privacidade.

Contato

Para qualquer dúvida sobre esta política de privacidade ou sobre o tratamento de dados pessoais, o usuário pode entrar em contato em: support@difmeil.com

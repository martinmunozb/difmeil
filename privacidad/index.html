Política de privacidad de Difmeil

Última actualización: 7 de septiembre de 2026 · English · Français · Deutsch · Português

Difmeil es una extensión de navegador diseñada para ayudar al usuario a gestionar y visualizar sus correos electrónicos de forma más cómoda desde su propio navegador.

Esta política de privacidad explica qué datos puede tratar Difmeil, para qué se utilizan y qué derechos tiene el usuario.

Datos que puede tratar Difmeil

Difmeil puede acceder a determinados datos de la cuenta de Google/Gmail del usuario, siempre que el usuario conceda los permisos necesarios mediante OAuth de Google.

Según las funcionalidades utilizadas, la extensión puede tratar:

  • Dirección de correo electrónico del usuario.
  • Lista de correos electrónicos.
  • Remitente, destinatario, asunto, fecha y etiquetas de los correos.
  • Estado de lectura, destacados, archivados u otras acciones de organización.
  • Contenido de los correos únicamente cuando sea necesario para mostrarlo al usuario dentro de la extensión.
  • Datos técnicos básicos necesarios para el funcionamiento de la extensión.

Difmeil no vende datos personales del usuario ni los utiliza para publicidad de terceros.

Finalidad del tratamiento

Los datos se utilizan únicamente para:

  • Permitir al usuario ver, organizar y gestionar sus correos.
  • Ejecutar acciones solicitadas por el usuario, como marcar correos como leídos, archivarlos, eliminarlos o enviarlos.
  • Mejorar la experiencia de uso dentro de la extensión.
  • Mantener la seguridad y el correcto funcionamiento del servicio.

Uso de datos de Google

El uso y transferencia de información recibida desde las APIs de Google se realiza de acuerdo con la política de datos de usuario de los servicios API de Google, incluyendo los requisitos de uso limitado.

Difmeil solo solicita los permisos necesarios para prestar sus funcionalidades. Los datos obtenidos mediante APIs de Google no se utilizan para publicidad, venta de datos, elaboración de perfiles comerciales ni cesión a terceros no necesarios para la prestación del servicio.

Permisos de Google solicitados

Para que Difmeil pueda funcionar correctamente, la extensión puede solicitar permisos de acceso a la cuenta de Google del usuario mediante OAuth. Estos permisos solo se utilizan para ejecutar las funciones que el usuario solicita dentro de la extensión.

Difmeil puede solicitar los siguientes permisos:

  • https://www.googleapis.com/auth/gmail.modify: permite leer, organizar y modificar correos de Gmail, por ejemplo marcar correos como leídos, archivarlos, aplicar etiquetas o moverlos cuando el usuario realiza una acción dentro de la extensión.
  • https://www.googleapis.com/auth/gmail.send: permite enviar correos desde la cuenta de Gmail del usuario únicamente cuando el usuario solicita expresamente el envío desde Difmeil.
  • https://www.googleapis.com/auth/contacts.other.readonly: permite consultar contactos u otros contactos de Google en modo solo lectura para facilitar funciones como autocompletado de destinatarios o identificación de contactos.

Difmeil no utiliza estos permisos para vender datos, mostrar publicidad personalizada, crear perfiles comerciales ni compartir información con terceros no necesarios para prestar el servicio.

Los tokens de autenticación se gestionan de forma segura y se utilizan únicamente para mantener la sesión y ejecutar las funciones autorizadas por el usuario. La configuración local de la extensión puede guardarse en chrome.storage.local para recordar preferencias del usuario dentro del navegador.

Almacenamiento de datos

Difmeil puede almacenar ciertos datos localmente en el navegador del usuario para recordar preferencias, configuración o mejorar el funcionamiento de la extensión.

Salvo que sea estrictamente necesario para prestar el servicio, Difmeil no almacena el contenido de los correos en servidores propios.

Cuando sea necesario para el funcionamiento técnico de la extensión, Difmeil podrá utilizar una función backend segura para completar el proceso OAuth y canjear códigos de autorización por tokens de acceso. Estos tokens se usan únicamente para autenticar al usuario y ejecutar las acciones autorizadas.

Compartición de datos con terceros

Difmeil no vende ni alquila datos personales.

Los datos solo podrán compartirse cuando sea necesario para:

  • Cumplir obligaciones legales.
  • Prestar el servicio solicitado por el usuario.
  • Mantener la seguridad técnica de la extensión.
  • Usar proveedores técnicos necesarios para el funcionamiento del servicio, siempre bajo medidas adecuadas de protección.

Seguridad

Difmeil aplica medidas razonables para proteger los datos del usuario frente a accesos no autorizados, pérdida, alteración o uso indebido.

Aun así, ningún sistema informático es completamente seguro, por lo que no puede garantizarse una seguridad absoluta.

Conservación de datos

Los datos se conservarán únicamente durante el tiempo necesario para cumplir las finalidades descritas en esta política o mientras el usuario mantenga instalada y conectada la extensión.

El usuario puede revocar el acceso de Difmeil a su cuenta de Google en cualquier momento desde la configuración de seguridad de su cuenta de Google.

Derechos del usuario

El usuario puede ejercer sus derechos de acceso, rectificación, supresión, oposición, limitación del tratamiento y portabilidad escribiendo a: support@difmeil.com

También puede presentar una reclamación ante la Agencia Española de Protección de Datos si considera que el tratamiento de sus datos no se ajusta a la normativa aplicable.

Menores de edad

Difmeil no está dirigida específicamente a menores de edad. Si un menor utiliza la extensión, deberá hacerlo con autorización de sus padres, tutores o representantes legales cuando sea exigible.

Cambios en esta política

Difmeil podrá actualizar esta política de privacidad cuando sea necesario por cambios legales, técnicos o funcionales. La versión actualizada estará disponible en la página oficial de privacidad.

Contacto

Para cualquier duda sobre esta política de privacidad o sobre el tratamiento de datos personales, el usuario puede contactar en: support@difmeil.com
